# Brian Ombongi Ondieki - Portfolio

## How to run
1. Extract this folder into your XAMPP `htdocs` directory.
2. Open the folder in Visual Studio Code.
3. Start Apache in XAMPP if you want to run it through localhost.
4. Visit:
   http://localhost/brian_ombongi_portfolio/

You can also double-click `index.html` to preview the website directly.

- script.js
- assets/construction-management-system.png
